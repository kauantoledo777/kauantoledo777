## 🚀 Projeto principal

### 💈 NAVØR – Barber • Lounge | Site da barbearia

Site desenvolvido em grupo (ADS / UNICID) para uma barbearia que oferece serviços de cuidados pessoais e estética, além da venda de produtos e bebidas. A estrutura foi pensada para receber, no futuro, a integração com um sistema ERP. **Atuei como desenvolvedor Front-end.**

| | |
|---|---|
| 🧭 **Páginas** | Início, Sobre, Equipe, Loja, Lounge, Galeria, Depoimentos, Agendamento, Contato e Localização |
| 🏷️ **HTML semântico** | `header`, `nav`, `main`, `section`, `article` e `footer`, com validação no **W3C Validator** |
| 📅 **Agendamento** | Formulário com escolha de especialista, serviço, data e horário, capturado via **JavaScript** |
| 📍 **Localização** | Mapa incorporado para o cliente encontrar a barbearia |
| 📝 **Documentação** | Diários de bordo semanais e relatório de domínio e hospedagem |
| 🛠️ **Tecnologias** | HTML5 · CSS3 · JavaScript · Git/GitHub · GitHub Pages |
